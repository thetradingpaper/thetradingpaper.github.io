# data/

Auto-generated by `.github/workflows/snapshot.yml` → `scripts/snapshot.js`.

- `prices.json` — latest quotes per ticker (site uses as fallback when browser-side Yahoo fetch fails)
- `history.json` — one row per day: each book's value + total deposited (drives The Mountain chart)

Do not edit `prices.json` by hand. You MAY edit `history.json` to fix a bad day.
